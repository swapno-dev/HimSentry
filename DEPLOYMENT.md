# Deployment checklist

1. Push this folder to GitHub.
2. Create a Node web service on your preferred host.
3. Build: `npm install && npm run build`
4. Start: `npm start`
5. Set the platform to use the assigned `PORT`.
6. Open the public HTTPS URL.
7. Click **QR / SHARE** in HimSentry to generate the phone-ready QR code.
8. Test `/api/health` before the hackathon demo.

For a polished judging demo, use a real public HTTPS domain rather than a localhost address.
